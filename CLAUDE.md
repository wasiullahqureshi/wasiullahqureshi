# Instructions for Claude (any session, any future version)

## Ideas log
The owner often describes new project ideas in chats (including from the mobile app).
- When the user says "note this idea", "save this idea", or describes a new project/app idea, record it in `docs/ideas/<short-name>.md` using the template in `docs/ideas/README.md`, and add a row to the index table there.
- If the idea extends an existing one, update that file instead of creating a new one.
- Keep the owner's wording and intent; tidy it, don't invent requirements. Put unknowns under "Open questions".
- Commit and push to the session's designated branch. Do not open a pull request unless asked.
- Before adding, read `docs/ideas/README.md` to see what ideas already exist.
